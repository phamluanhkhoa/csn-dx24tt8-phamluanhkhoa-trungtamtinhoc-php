# Báo cáo tiến độ

Thư mục này dùng để lưu báo cáo tiến độ đồ án theo từng tuần theo yêu cầu của giảng viên.

## Cách sử dụng

Mỗi tuần:
1. Hoàn thiện những phần thực tế đã làm.
2. Cập nhật file báo cáo của tuần đó.
3. Nếu có thể, lưu bản cuối cùng dưới dạng PDF/DOCX để upload vào repository.
4. Commit cả báo cáo và phần source code đã thay đổi.

**Lưu ý:** Các file `TuanXX_Mau_BaoCaoTienDo.md` trong bộ project là mẫu.
Sinh viên cần chỉnh ngày, kết quả, khó khăn và công việc thực tế trước khi nộp.
